## 3. Product & Manufacturing Scope
- **Products**:
  1. *Solid Rivets*: Brass Round head, Copper Mushroom Head, MS Dimple head, MS Knurled Shank, MS Step Head, MS Step Shank.
  2. *Semi-Tubular Rivets*: Brass Mushroom Head, Copper Flat Head, MS Double Shank, MS Flat Head, MS Hexagonal Head, SS Flat Head.
  3. *Tubular Rivets*: Brass Flat Head, Brass Tubular, MS Button Rivet, MS Counter Sink, MS Head Knurled, MS Step Rivet.
- **Materials**: Mild Steel (MS), Stainless Steel (SS), Brass, Copper, Aluminum, Specialized Alloys.
- **Services & Plant Capabilities**:
  1. *Cold Forging*: Precision high-speed cold heading process.
  2. *Annealing*: Heat treatment to normalize interatomic space after forging and increase ductility/workability.
  3. *Ultrasonic Cleaning*: 3 to 6 minute solvent agitation via ultrasound waves.
  4. *In-House Automated Plating*: 80-tonne capacity automated finishing plant (Zinc, Nickel, Copper, Brass, Tin, Passivations).

## 4. Technical Architecture & Tooling
- **Architecture**: Multi-page high-performance web architecture with modular modern JavaScript and CSS.
- **Styling**: Tailwind CSS + Custom Industrial theme (`custom-industrial.css`).
- **3D Engine**: Three.js procedural WebGL models based on `img2threejs` principles (Solid, Semi-Tubular, Tubular rivets with dynamic PBR metallic materials and cutaway cross-section inspection).
- **Motion & Interaction**: GSAP 3 + ScrollTrigger for pinned sequences, magnetic buttons, coordinate HUD, and cursor spotlight.
- **Verification**: Playwright MCP for multi-viewport validation (Desktop 1440px, Tablet 768px, Mobile 390px), console audits, and RFQ form functional verification.
